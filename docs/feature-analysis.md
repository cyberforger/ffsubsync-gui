# 旧版功能与重实现范围

## 旧版提供的功能

- Electron 单窗口桌面应用，最小窗口尺寸为 900 × 600。
- 通过系统文件选择框批量选择视频和字幕；视频支持 MP4、MKV、AVI、MOV、WMV、FLV、WebM，字幕支持 SRT、ASS、SSA、SUB、VTT。
- 界面显示两类文件的数量、选择的文件名、执行日志和批次进度。每次运行按数组位置把视频与字幕一一对应，逐项串行调用本机 `ffs` 命令。
- 输出文件放在视频目录中，文件主名取视频主名，扩展名取输入字幕扩展名。
- 允许移除列表项、清空日志；同步时通过 IPC 推送逐项进度和最终结果。
- Electron 开启 `contextIsolation` 并关闭 `nodeIntegration`；功能通过 preload 暴露的 IPC API 调用。
- 用 electron-builder 生成 Windows x64 portable 包。

## 已发现的功能缺口与风险

- 两类文件数量相同就会开放同步，但不会依据名称配对；错序时可能把无关字幕传给视频。
- 页面显示拖拽提示并处理拖拽悬停状态，但没有 `drop` 事件处理器，因此文件实际上不能拖入列表。
- 目标输出名与常见输入字幕名相同；直接同步会与输入文件冲突。旧版没有备份、临时输出或覆盖保护。
- 路径被拼进带引号的 shell 命令并交给 `exec`。路径中的特殊字符可能破坏参数边界，且 shell 参与执行没有必要。
- 成功状态部分依赖 stdout/stderr 中的特定文本；进程退出码才是更可靠的成功判断。
- UI 使用 `innerHTML` 插入文件路径和日志内容，文件名或错误文本未转义。
- 没有检查 `ffs` 是否可用；FFSubSync 和 ffmpeg/ffprobe 需要用户另行安装。
- 不保存最近任务，也没有逐项重试或详细的失败原因查看。

## 新版重实现范围

- 保留旧版的格式、批量同步、视频名输出、串行进度和日志能力。
- 视频和字幕分别按文件名自然排序后，按列表位置一一配对；每个文件都可独立上移或下移。
- 视频与字幕数量不同时禁用开始同步，并显示两侧数量，直到补齐或移除文件。
- 输出始终采用 `<视频主名>.<字幕扩展名>`，便于播放器自动识别。先写入同目录临时文件；目标已存在时将旧目标保留为带 `.original` 标记的副本，再用新文件原子替换目标。
- 通过不启用 shell 的子进程参数调用 `ffs`，提供 CLI 可用性检查、逐项状态、可查看的错误信息和成功输出的打开位置。
- 实现真实文件拖放并安全渲染路径与进程输出。
- 设置页允许检查和修改 `ffs` 可执行文件路径。
