## Surface

Scope: Windows desktop batch synchronizer. Mode: Operate. The user adds local videos and subtitles, corrects any unmatched pairing, then runs the local `ffs` command and reviews each result.

## Direction contract

THESIS: Each job is a numbered track on a cassette inlay: one video faces one subtitle, and only a confirmed one-to-one match can run.

OWN-WORLD: Inlay-stock ivory with quiet ruled lines; ballpoint navy and faded blue carry file labels and match marks; pressed fold rules define the spine and central pair rail. Red ink is reserved for mismatches and failures.

STORY: Drop files into their labeled columns. Normalized matching names connect automatically; duplicates stay unresolved until the user chooses a subtitle for each video. A single ready count, row states, and actual CLI output explain what can run and what needs attention.

FIRST VIEWPORT: A slim vertical J-card spine holds the batch number and CLI health. The inlay opens into a masthead and large readiness count above two balanced file columns, joined by a continuous numbered pair rail. Output naming and a full-width run control anchor the lower fold; execution details expand below it.

FORM: Assigned direction “蓝墨 J-card · 磁带内页”, selected from the direction roll with seed `7d3ffa00`. Dropping a file creates a numbered track; a short blue connection mark confirms a unique automatic pair. Settings and installation guidance use the same printed-label grammar.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
